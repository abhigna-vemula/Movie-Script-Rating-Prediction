# Movie Script Rating Prediction

An NLP + Machine Learning project that predicts IMDb-style movie ratings from screenplay text using TF-IDF and Linear SVR.

## Features
- Text preprocessing
- TF-IDF vectorization
- Linear SVR regression
- NLP pipeline
- Script rating prediction

## Technologies Used
- Python
- Scikit-learn
- Pandas
- NLP
- Google Colab

## Results
- R² Score: 0.787
- RMSE: 1.23
